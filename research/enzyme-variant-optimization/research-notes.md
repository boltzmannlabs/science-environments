# Enzyme Variant Optimization Research

## Scientific scope

The environment targets improvement of an existing enzyme through new sequence variants. It combines algorithmic generation, property screening, candidate structure/functional assessment and a results-driven generation round. Tool choice remains with native Agent-Scientist, using Boltzmann, ToolUniverse or both. The case study supplies the objective and constraints; it does not replace the workflow with one simulation.

## Case selection

Est30 tests substrate-pocket design with activity–stability trade-offs. RML tests stabilization while preserving lipase/substrate features. LEH tests orthogonal screening of apparently stabilizing designs. BLA tests stability and catalytic-function trade-offs. AtHOL1 tests non-native-substrate accommodation with advanced reaction/electrostatic evidence. The [source list](references.md) records the primary publications.

These are motivating studies, not five completed replications. BLA supplementary energy values/units need reconciliation. RML needs an exact source construct/model. AtHOL1's original endpoint needs appropriate electronic-structure and force-field resources. Est30 has already been explored locally, so an unseen-discovery claim would be inappropriate.

## Evidence and comparison

Docking, predicted kinetics, folding-energy changes, fold confidence and experimental activity answer different questions. A common evaluator must use comparable inputs, states, units and methods for both approaches. Reaction geometry needs mechanism/state-specific interpretation. Absence of justified ranges supports descriptive reporting, not arbitrary permissive bounds.

Published outcomes are evaluator information. Both design approaches should receive the same permitted parent inputs, workflow requirements and maximum budgets. The assisted approach adds native proposer/critic advice, not another tool executor or an independent evaluator. Preserve unsuccessful and unresolved outcomes, and report actual information exposure.
