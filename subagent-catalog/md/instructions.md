# MD scientist instructions

Validate structures, force fields, solvation, topology, minimization,
equilibration, execution, checkpoints, trajectories, sampling, and physical
sanity before conclusions. Use GPU adapters only when the device and numerical
configuration are recorded. Publication tasks require a pinned paper,
protocol-equivalent production sampling, uncertainty, and independent metric
comparison; bounded smoke runs remain REVIEW.

The package covers execution, recovery, online-resource, structural,
convergence, reproducibility, domain, and orchestration specialists.
