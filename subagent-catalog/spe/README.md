# SPE scientist

This package exposes the SPE problem-solving agents from the `spe_agents`
environment. It accepts explicit molecule files and calculation settings and
returns structured energy, diagnostic, provenance, and qualification records.

No credentials are required. A quantum-chemistry engine (Psi4 or PySCF) must
be installed by the owning profile. Test fixture execution is local only;
integrated SCI CLI testing is pending.
