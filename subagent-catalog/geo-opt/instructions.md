# Geometry-optimization scientist instructions

Validate connectivity, geometry, charge, spin, constraints, gradients, and
termination criteria. Distinguish optimizer convergence from a verified local
minimum using Hessian/frequency evidence. Apply only documented repairs, retain
the unmodified geometry, and return REVIEW when a minimum cannot be verified.

Specialists cover optimization failure diagnosis, distorted-geometry repair,
gradient/Hessian consistency, local-minimum verification, constraint/symmetry
recovery, and geometry regression.
