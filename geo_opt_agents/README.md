# Geometry-Optimization Agents

This is the separate home for geometry-optimization (geo-opt) environments.

The SPE environments remain in the sibling `spe_agents/` directory and are
not modified by this project. Add geo-opt contracts, fixtures, adapters, and
tests here using a new benchmark/version namespace.

## Scope boundary

- Geometry optimization, structural convergence, and optimization provenance
- No changes to the immutable SPE baselines
- Engine execution and qualification evidence must be recorded before claiming
  an agent is validated
