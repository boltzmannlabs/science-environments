4. Blocking gaps to a scientifically usable environment (per selected case)
P0 — Confirm case and rights: select Glenmark or Ajanta (or provide another recall identifier); identify the responsible data owner, access permissions, permitted local processing, and controlled-record verification/sign-off. FDA API provenance is not authentication of a manufacturer's GMP documents.
P0 — Controlled method and specifications: approved lot/product-specific dissolution SOP or compendial procedure, version and effective dates, apparatus, media, agitation, sampling times, analytical assay and units, stage-specific acceptance criteria, and relevant method changes. Public recall text provides NONE of these; no threshold must be guessed.
P0 — Actual measurements: source-authenticated lot-level profiles/individual tablet results, units/timepoints, replicates, run/analyst/instrument/calibration identifiers, reference lots, OOS investigation, and controlled provenance. Recall reason is NOT a measured profile. Restrict import to authorized sources; label values measured only after provenance checks.
P0 — Batch/process/materials: actual batch formula (dose and potency basis, ingredient quantities/grades), raw-material lots/tests, granulation/compression/coating settings, tablet weight/hardness/porosity where recorded, storage and stability history, deviations and change controls. Public label ingredient names do not establish levels or process.
P1 — Integration contracts: platform owner must document and approve source retrieval, controlled-record storage, compatibility/stability, dissolution analysis/prediction, statistics/DoE and reporting APIs (schemas, versions, permissions, limits, authentication outside repository). Current SCI registry has terminal/file/skills enabled, web and delegation disabled, and zero MCP servers. `sci plugins show boltzmann` identifies a bundled Boltzmann connector v1.3.0, but it is NOT enabled and explicitly locked until `/add_boltzmann` validates the user's key. Consequently its actual scientific API contracts and access could not be checked through a live tool; do not bypass authentication or invent endpoints. Public Zenodo records API access is independent of that connector. No approved manufacturing/dissolution connector exists in this session; adapters correctly return tool_unavailable.
P1 — Candidate and experiment governance: approve formulation bounds, criteria, dose basis and budget before validating or ranking candidates; require explicit human approval and authorized execution confirmation for any physical experiment, regulated-record update, spend or manufacturing change.
P2 — Scientific evaluation: first audit literature table/figure transcription, match formulation features, license and group structure, then decide whether public research data are fit for a separately labelled exploratory literature benchmark. These papers cannot serve as a recalled-lot QC holdout. Curate legally usable independent measured formulations, freeze group/lot-aware splits, assess applicability and uncertainty calibration, then run matched-budget A conventional, B direct-tool, C specialist and D improved-model comparisons. Passing software tests or synthetic fixtures are NOT evidence of predictive validity or specialist benefit.
