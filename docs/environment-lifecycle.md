# Environment Lifecycle

Each environment declares one maturity status in its `README.md`:

1. **Proposed** — idea identified, requirements incomplete.
2. **Specification** — scientific requirements documented.
3. **In Progress** — implementation or qualification underway.
4. **Implemented** — required implementation exists.
5. **Validated** — declared validation criteria have evidence.
6. **Deprecated** — not recommended for new use.

Status must reflect available evidence. Contract checks or an illustrative
example alone do not establish production validation. Limitations and
uncompleted qualification phases remain documented beside the status.
