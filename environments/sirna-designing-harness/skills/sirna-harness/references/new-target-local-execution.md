## Screen and critique both strands

Bind exact scanner, reference and cached global seed hashes before reuse. Distinguish exhaustive declared-scope ungapped0–2-substitution screening from native Bowtie2 heuristic/score-floor behavior. Count alignments, distinct transcripts and genes separately; report skipped ambiguous windows, gaps/variants and whole-transcript versus UTR scope. Subtract intended-gene seed occurrences and transcript counts exactly, preserving overlapping motifs and both strand orientations.

Inspect passenger-seed annotations as well as guide annotations. Neutral-scaffold cancer-cell viability is neither exact-duplex toxicity nor innate immune safety; unknown loading/chemistry/context can reverse interpretation. A two-annotation Pareto review may expose risks without new cutoffs or reweighting, but must not be represented as a clinical-safety rank.

## Compare compatible pools honestly

Report generated site records, unique guides, each tool's actual scored/NOT_RUN counts, broad potency pool and conditional common-comparison pool separately. Native Bench may supply scores only for operational passers; restrict direct all-method rank comparisons accordingly and keep broader Ridge ranks labeled separately. Preserve frozen combined weights and raw endpoints. Unbounded Ridge values are extrapolations, not biological inhibition above100 percent. Without measured exact-construct labels, do not invent Precision@K/NDCG efficacy accuracy or confidence intervals; rank agreement is only agreement, not independent validation.

## Multi-reference and mutation-arm studies

Require exact site presence in every user-declared coverage reference; map all coordinates independently and classify CDS/UTR separately per annotation, since the same shared RNA segment can encode protein in one transcript but lie in a UTR in another. Treat global collinear blocks as an explanatory map and exact per-site occurrence lists as authoritative when repeat placements differ.

Keep transcript sharing distinct from mutant-allele coverage. If no exact nucleotide mutation/reference context and mutant-versus-wild-type objective are specified, retain BLOCKED_PENDING_MUTATION_SPECIFICATION, construct no hypothetical mutant and generate zero mutation-selective candidates. Keep cell/dose/delivery requirements separate from the minimum inputs that unlock context-independent mutation sequence work.

Reuse efficacy only for identical guide and full57nt model-context inputs across transcripts; record that this is input-equivalence reuse, not independent evidence or uniform cellular knockdown. Compare local folding inputs separately because identical57nt inputs can still have distinct179nt structure contexts. Evaluate only new distinct contexts and preserve their raw folding outputs.

## Recover ambiguous native tool timeouts

Treat an RPC/interface timeout as ambiguous execution, not proof the native process stopped. Locate the matching request by candidate CSV/input identity, inspect the same runner/process/log and read its exact result/provenance after completion. Never submit a duplicate while the first job is live or ambiguous. Record the interface failure and actual native outcome separately.

## Preserve specificity failures after operational passes

Distinguish a passed inherited operational filter from perfect gene exclusivity on both strands. A permissive hit-count default can pass candidates with exact outside-gene matches. Report those matches as failed explicitly scoped optional exclusivity diagnostics unless the user already declared an exclusivity gate; do not silently change frozen thresholds or present flagged entries as gene-exclusive recommendations. Emit the smaller no-detected-perfect-match review subset with residual near-match/seed/reference limits and keep failed diagnostics separate from missing biological acceptance evidence. Annotate full-length and seed opportunities for relevant paralog/pseudogene transcripts independently; no detected near match does not exclude seed-mediated effects.

## Audit completed studies read-only

Discover actual files before choosing inputs, verify the original manifest/receipt bindings, and snapshot every original file before and after a post-run audit. Write audit scripts, derived tables, preserved reference subsets and receipts only in a new sibling directory; do not run an old verifier that writes back into the completed study.

Reproduce flagged diagnostics by extracting the saved query/reference windows from hash-checked inputs rather than launching generation, inference or another transcriptome search. Report the siRNA strand evaluated separately from transcript/genomic orientation, include derived mismatch positions, and never imply measured passenger loading or repression from an alignment. Count isoform alignments separately from distinct genes; a passenger co-match can be missed by a guide-only native screen.

Prespecify descriptive Spearman/average-tie ranks, Kendall tau-b, matched cohorts and K before computing an audit's ranking comparisons. Report exact-K tie handling and fractional boundary-tie sensitivity. Keep an existing cohort-normalized combined score unchanged when restricting its cohort; do not fabricate missing combined or rejected-candidate scores. Use independent standard-library rank oracles and numerical fixtures, not the same metric implementation as its own verifier.

Interpret conditional rank agreement as predictor agreement, not accuracy or independent validation. Separate a defensible multi-candidate review panel from an unstable numerical ordering, preserve extrapolation flags, and do not turn stronger shared-checkpoint agreement into biological confidence or invent confidence intervals without an appropriate sampling design.

## Ranking sensitivity without new inference

Treat removal of out-of-range Ridge estimates as a declared numerical sensitivity stratum, not an automatic biological exclusion rule. Retain raw values and distinguish excluding candidates from omitting a method. Reuse verified baseline correlations/top-K tables and compute only the new restricted-pool comparisons. Label K greater than the remaining population NOT_APPLICABLE and K equal to the population non-discriminating; whole-population overlap cannot establish robustness.

Separate actual predictor availability from simulated missingness. Compare shared methods before and after a complete-case restriction, disclose policy-related missingness, and report rank-position or top-K membership shifts as cohort/denominator effects rather than biological changes. Never assign sentinel or imputed prediction values to excluded candidates merely to compute set overlap; select and weight each cohort's top-K directly. Preserve existing cohort-normalized composite scores and do not silently renormalize them after restriction.

Retain a conditional review panel when warnings alone lack validated biological exclusion criteria, while deferring a definitive potency ordering. A nominal-range subset is not automatically better calibrated, safer or experimentally supported. Record genuinely new inference, folding, screening and context-dependent assessments as NOT_RUN when prohibited or unsupported.
