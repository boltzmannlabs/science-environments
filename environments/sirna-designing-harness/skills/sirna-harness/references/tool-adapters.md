# Scientific tools and adapter contracts

This skill does not register tools. Discover the destination session's tools, schemas, code/version, assets and authorization; inspect complete contracts before use. Historical names below aid discovery, not proof they exist or share the same schema on another system.

Observed local interfaces: oligoformer_generate / oligoformer_status; sirna_bench_status / sirna_bench_predict / sirna_bench_run / sirna_bench_validate_generated. OligoFormer generation and native assessment were actually exercised on the originating installation; verify again on each destination. A status tool reports availability, not fresh successful inference.

Use the actual returned run_directory/job ID; persist submit-once receipts and input hashes. A strict generation handoff binds exact top-N artifact/count/target identity. For a different inspected subset, use an explicitly supported direct supplied-candidate assessment with checked CSV instead of editing a source manifest.

Require an adapter record containing tool/provider name, complete schema/version, source/checkpoint identity, input files/hashes, exact guide/passenger interpretation, length/overhang/chemistry envelope, accession/version/coordinates, context policy, reference scope, parameters, inference mode, counts/statuses, raw artifacts and resource usage. Never assume column names or that a guide column is antisense without verification.

The exercised strict human assessment envelope is19nt unambiguous RNA guide, optional exact reverse-complement passenger, unique exact primary site and documented full context. Native model/pipeline length options outside that envelope are not proof of applicability. Nonhuman work needs matching transcript/seed references and model-domain evidence.

Protect integrations: isolate scientific environments from SCI; clean inherited PYTHONPATH/PYTHONHOME/VIRTUAL_ENV as required by the wrapper; stage writable caches/results away from original sources; avoid shell interpolation; preserve original headers while using approved safe working IDs. Inspect help/source before selecting inference mode because a bare model CLI may train or load weights during import/help. Never copy source-restricted dependencies as part of this skill.

Current known caveats to recheck: stock OligoFormer eval/dropout mode; class1 output times1.341 scale; distinct RN.Ai/RNAiSpline endpoints; siRNADiscovery code_only without weights; guide-focused native full/seed screen; permissive full-hit thresholds; Bowtie score-floor limiting apparent mismatch scope; native POTS percentile direction; optional NUPACK/RNAstructure licensing/installation; full-core versus final modified-duplex applicability. Do not silently patch scientific behavior or claim versioned corrections are original outputs.

Large model installs, reference/index builds, remote sequence transfer, credential configuration and paid jobs require applicable user authorization. A skill does not grant that authorization. On missing session plugin access, explain the setup gap instead of substituting a generator. Keep missing optional assessments visible and continue unrelated supported work.
