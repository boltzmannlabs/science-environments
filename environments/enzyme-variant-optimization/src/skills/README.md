# Workflow skills

The enzyme-coordinator skill defines the main agent's delegation, recovery, continuation and final-review responsibilities for new assisted runs. Install its reviewed directory in the dedicated SCI profile.

The method, recovery and evaluator specialists are distributed through Agent Scientist's reviewed subagent catalog. Their packaged skills remain with those installations. Use the environment startup instructions to verify version 1.2.0 before executing a new run. Historical run artifacts retain their original definitions and accounting.
