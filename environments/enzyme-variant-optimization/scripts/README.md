# Launch and evaluation entry points

`RUN_AGENT_ALONE.txt` and `RUN_WITH_SPECIALIST.txt` start the selected native SCI approach; select a task/version and unique run ID first.
`evaluate_results.py` invokes the retained offline helper on sealed selections and reviewer-supplied measurements.
SCI provides execution, permissions, delegation and job tracking; reviewed generated workflow skills/code belong in `src/`.
