# BLA high-temperature performance: agent-alone results

## What is compared

Our best available predicted-Tm candidate is compared with the selected parent and reconstructed K319W/E336S references using common property predictors. K319W and E336S lead different published experimental endpoints.

## Parent used

WP_061576039.1 mature residues 30–512, 483 residues; no expression tag.

This matches the study’s stated protein accession. The structural reference 1BLI differs at six mature positions, so it was used for structural mapping rather than silently replacing the parent sequence. Complete expression-construct equivalence remains to be checked.

## Calculations

Reference mutations must be mapped to the correct mature numbering. Newly calculated Tm and solubility values are predictions in this work, separate from the paper’s measured Tm and half-life.

The benchmark keeps published numbers and values calculated in this work separately labeled. Parent-relative changes use the exact parent recorded for each candidate.
