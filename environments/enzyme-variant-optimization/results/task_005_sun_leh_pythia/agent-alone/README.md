# Sun LEH / Pythia: agent-alone results

## What is compared

Our retained D101V/T85V candidates and reconstructed P57A reference are assessed using common sequence-property predictors. P57A was chosen as the paper’s best reported experimental Tm mutant; its original numerical Pythia score has not been established.

## Parent used

Native 149-residue Q9ZAG3, using the experimental 1NWW structure.

The native enzyme matches the study’s named LEH and cited structural-reference rationale. Original Sun coordinate processing, assembly and expression-tag details remain unverified.

## Calculations

Pythia scores are unitless. The original scan used summed C/P scores with mean-score sensitivity retained separately. N-terminal positions without coordinates were not scored. New Tm/solubility calculations occurred after selection.

The benchmark keeps published numbers and values calculated in this work separately labeled. Parent-relative changes use the exact parent recorded for each candidate.

## Run status

The Pythia scan is complete. D101V changes catalytic Asp101; its favorable property score does not establish retained enzyme function.
