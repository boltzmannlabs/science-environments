# Decisions and exclusions — LEH stability v12 assisted run

## Initial generation failure (attempt 7)
`Random_Controlled_Mutagenesis` (doc 6b07efa61715676d03408d5c) returned 10 sequences with lengths 135-159 aa (parent 149), 117-145 substitutions each (cap 8) and altered protected sites 53/55/99/101/132. Task-ineligible. enzyme-recovery receipt: `results/specialist_receipts/enzyme-recovery_mutagenesis_failure.json`. Diagnosis: documented contract has no field for output length, total substitution cap or enforced protection; the backend did not honor `indices`/`mutaions_per_epoch`. No identical retry. Corrective action: switch to native `stability-binding-ddg`, which preserves chain length and changes exactly the listed 1-based sites (<=8). Its binding-DDg sign convention is inconsistent in the docs, so it is used only as a generator; folding stability is scored by the frozen `Enzymes/tmPred_enzymes` endpoint.
