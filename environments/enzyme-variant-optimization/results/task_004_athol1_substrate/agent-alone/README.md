# AtHOL1 substrate expansion: agent-alone results

## What is compared

Our best available objective candidate is compared with its parent and V140T on the same declared construct. V140T is the published reference candidate for this comparison.

## Parent used

3LCC full 235-residue construct: native 227 residues plus LEHHHHHH.

3LCC is the structural reference cited by the study. We retained its complete deposited construct and fixed tag. The exact processed construct used in the paper’s simulations has not been verified.

## Calculations

New sequence-based Tm/solubility predictions are separate from the paper’s electrostatic field/stabilization calculations. Those methods measure different properties.

The benchmark keeps published numbers and values calculated in this work separately labeled. Parent-relative changes use the exact parent recorded for each candidate.

## Run status

The design pipeline is paused. The numerical screen, chemical preparation and written evidence review are retained; reaction-specific functional support remains open.
