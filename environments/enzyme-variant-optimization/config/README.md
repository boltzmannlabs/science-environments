# Proposed task configuration templates

No historical run in this publication review has an assigned configuration version. Existing task/version/approach JSON files are prospective templates for future launches. They are not evidence that a matching configured experiment occurred.

The current benchmark compares the published reference with agent-alone results only. Actual observed model/provider/settings are retained in each executed task’s `results/.../agent-alone/EXECUTION_METADATA.json`. MLDE remains excluded.
