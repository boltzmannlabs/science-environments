# Models and tools

The executable profile uses OpenMM custom harmonic bonds and repulsive
nonbonded interactions for a deliberately small bead-spring system. This
validates adapter plumbing only; it is not a MARTINI, SDK, membrane, or LLPS
qualification.

Every real CG result must record resolution, mapping, bead types, force-field
version, topology/parameter hashes, engine/platform, seed, replicas,
observables, and reference thermodynamic state.
