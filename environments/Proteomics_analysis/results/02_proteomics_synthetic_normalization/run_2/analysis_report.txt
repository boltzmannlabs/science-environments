Processing order:
1. Convert raw linear intensities to log2 (no pseudocount).
2. Centre each of the six samples at its log2 median (computed from observed values).
3. Impute each missing cell with the mean of the same protein's two same-condition replicates.
4. Re-centre each complete sample at its log2 median so every sample median is exactly 0.

Rationale:
- LFQ run-to-run technical differences (loading, injection, ionization) are
  multiplicative, so on the log2 scale they are additive per-sample offsets.
  Subtracting each sample's log2 median removes these offsets.
- Median centering rescales nothing, so within-sample protein ordering and
  Control/Treated fold changes (biological differences) are preserved.
- Each missing value has two same-protein, same-condition replicate partners
  remaining. In the shift-removed space these directly estimate the missing
  protein-condition value, which is more accurate than cross-protein KNN.
