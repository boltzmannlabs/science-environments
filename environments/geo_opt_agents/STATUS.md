# Geo-Opt Agents Status

**Lifecycle: In Progress — executable and partially validated.**

The package contains 18 geometry-optimization task cards, input contracts,
problem-solving contracts, optimizer/recovery workflows, and versioned water,
methane, ammonia, and ethane evidence.

Convergence classification is intentionally separate from minimum verification:
gradient/step tolerances, Hessian or frequency evidence, constraints, and
provenance are required for a scientific `PASS`.
