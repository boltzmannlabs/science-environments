# Acceptance and validation plan

The 18 specialists are accepted case by case. A pass requires independent
checks of the declared output contract, not merely a successful process exit.
The qualification summary and benchmark reports are the evidence source.

Minimum checks include finite coordinates and energies, convergence metrics,
constraint preservation, gradient integrity, Hessian/minimum evidence where
required, explicit failure categories and complete provenance. Unsupported
production systems remain limitations rather than implied passes.
