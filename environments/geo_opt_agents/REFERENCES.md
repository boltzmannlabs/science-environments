# Geo-Opt Agents References

- [CompMat-Bench](https://github.com/cz2014/CompMat-Bench), the benchmark
  structure that motivated the task/workflow/reference-artifact layout.
- Frozen molecular fixtures, engine metadata, and qualification reports in
  `cases/`, `references/`, `engine/`, and `reports/`.
- Contract and result schemas in `contracts/` and `schemas/`.

The benchmark records backend versions and calculation settings with the
corresponding artifacts. It does not claim a production reference where a
prepared complex, Hessian, or runtime dependency was unavailable.
