# MD-PAPER-002 environment specification

This task follows the paper-benchmark packet format: frozen input, reference
parameters, three agent configurations, a perturbed stop case, independent
input validation and separate execution/scientific qualification. It is an
atomistic conventional-MD computational-methodology benchmark. It does not
involve biological experimentation, pathogen engineering, biological
optimization, or experimental pathogen handling. CG, enhanced sampling and
free-energy methods are out of scope.

The evaluator distinguishes paper-reported settings from values inferred to
make an executable input and from values that remain unavailable. A valid
input/configuration check is not a production-MD or scientific-reproduction
claim.
