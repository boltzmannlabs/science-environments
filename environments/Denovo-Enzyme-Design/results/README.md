# Results

Result packages are organized as `results/<task-id>/<run-id>/` and use the same identifiers as their run records.

New generated scientific artifacts must follow the root repository artifact naming convention. The retained Task 001 scientific files predate that convention and keep their recorded filenames as explicitly classified legacy artifacts; migration-created control records use their prescribed fixed names. The package provenance records this distinction and does not imply that legacy filenames satisfy the generated-artifact component format.
