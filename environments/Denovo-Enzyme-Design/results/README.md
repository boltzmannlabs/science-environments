# Results

Result packages are organized as `results/<task-id>/<run-id>/` and use the same identifiers as their run records.

New generated scientific artifacts must follow the root repository artifact naming convention. The retained Task 001 package keeps its recorded filenames while its task, run and result identities are made explicit in the surrounding records.
