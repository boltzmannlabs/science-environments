# Status

**Maturity: Specification (draft).**

The model-first, simulation-second scientific specification and existing task definitions are packaged in the standard environment layout. The shared guide specifies no preset candidate, finalist or replica counts. Task-specific mandatory systems, conditions and sampling requirements remain unchanged.

## Available material

- The scientific workflow, assumptions, evidence requirements and completion criteria in `ENVIRONMENT_SPEC.md`.
- Capability-selection and licensing guidance in `MODELS_AND_TOOLS.md`.
- Task definitions covering computational conformational, protonation, contact and local hydration-energy assessments.
- Package-relative result paths and a portable external input-only bundle contract.
- Reserved directories containing `.gitkeep` placeholders; no substantive configurations or generated results.

## Outstanding work

Verify and supply molecular inputs, physical parameters and missing analysis definitions before affected calculations. Input bundles, source papers and expected numerical comparison values are not included in this package. Keep evaluator material outside the executing agent's context.

Runtime adapters, an executable controller, concrete configuration contracts, automated tests and benchmark fixtures remain unimplemented. Exact dependencies, model assets, versions and access conditions must be frozen for an actual run. Supporting literature and implementation choices still require scientific review.

The workflow must assess physiological binding retention, acidic release and structural integrity separately when those are the task's objectives. The current fixed-case computational observables are supporting assessments; they do not establish complete qualification of a new antibody design.

## Validation

Package checks cover the reserved directory layout, root documentation, local Markdown links, task catalogue, portable paths and preservation of scientific task content. These checks do not execute scientific models or simulations.

No model inference, production simulation, numerical reference comparison or bounded end-to-end scientific run has been performed as part of this contribution. Issue #162 remains open pending its outstanding executable-workflow and scientific-review requirements.
