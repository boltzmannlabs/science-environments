# SPE Agents Status

**Lifecycle: In Progress — executable specification and partially validated.**

The package defines single-point-energy task cards, electronic-state and method
contracts, recovery-agent contracts, benchmark fixtures, and validation tests.
Results must distinguish adapter execution from independent scientific
qualification.

## Qualification boundary

The current package supports input/method/state validation and reference-energy
workflow design. Open-shell, charged, QM/MM, MLIP, and cross-method claims
require engine-specific calculations, frozen references, and independent
repeat checks before being marked `PASS`.
