# Boltzmann SPE Validation Campaign

This directory contains the executable common-baseline and specialist test
campaigns. It separates input/preflight success from calculation success and
scientific acceptance.

## Campaigns

- `manifests/common_water_baseline.json`: the shared water input for environments
  01, 02, 06, 07, 08, and 09, where a single water structure exercises a useful
  portion of the role. Other environments use their specialist workflow because
  water alone would not test their scientific contract.
- `manifests/active_18_agent_roster.json`: the authoritative active roster. IDs
  13 and 16 are retired; surviving IDs are not renumbered.
- `manifests/initial_54_cases.json`: valid, invalid, and independent-reference
  cases for every active environment—54 cases total.
- `manifests/initial_60_cases.json`: frozen historical 20-agent input retained
  for provenance; it is excluded from active gates.
- `fixtures/structures/`: deterministic fixed geometries. The aspirin and ethanol
  structures were generated by `scripts/build_initial_campaign.py` using RDKit
  ETKDGv3 and MMFF94 with recorded seeds. They are workflow fixtures, not
  independently validated quantum-chemistry references.
- `fixtures/artifacts/`: one preserved historical water record and two deliberate
  derivatives for environment-20 accept/reject/flag tests.
- `prompts/`: one filled specialist prompt per environment.

The source request used basis notation `6-31G(d)`. The inspected legacy backend
allow-list uses the PySCF spelling `6-31G*`, so manifests preserve the source
notation while submitting the declared backend spelling. This is a notation
alias, not a change in basis.

## Rebuild and run

From the repository root:

```bash
python scripts/build_initial_campaign.py
python scripts/run_initial_campaign.py
python scripts/run_initial_campaign.py \
  --manifest campaign/manifests/common_water_baseline.json \
  --output reports/common_water_baseline_results.json
```

Each run writes JSON evidence plus a CSV ledger containing test identity, status,
energy difference, scientific validity, error handling, provenance, and runtime.

## Current execution boundary

The active 54-case and common-water reports separate preflight/audit state from
live execution. A subsequent local adapter smoke test has
executed Agent 01 water, methane, and ammonia successfully through the actual
PySCF/GPU4PySCF module. See
`reports/live_spe_module/agent_01_smoke_summary.md`. The remaining campaign cases
have not been submitted. Missing numerical references remain `review`, with null
energy differences and tolerances.

Validated Cu clusters, QM/MM partitions, cyclohexane conformer identities, and
MLIP models/reference datasets are external
prerequisites. The campaign intentionally does not invent them.
