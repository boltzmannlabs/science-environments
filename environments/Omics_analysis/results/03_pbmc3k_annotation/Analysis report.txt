Uncertainty and limitations:
- Cell-type assignments are at cluster granularity; individual cells can be misclassified, including doublets and transitional phenotypes. Tentative clusters 3 and 5 contain conflicting signatures; they are not claimed to be purified subsets.
- Marker enrichment in the same clustering dataset is descriptive, not independent validation. Small cluster sizes, dropout, ambient RNA and possible doublets affect interpretation; no experimental confirmation is provided.
- No sample/donor covariates, doublet scores, reference model predictions or UMAP coordinates were supplied. The dot plot is not a cell-embedding plot; no cell-level model was run.
- Wilcoxon tests treat cells as units and may produce extremely small adjusted p-values (including numerical underflow to 0); this is not evidence of independent biological replication. Runtime warnings for zero-variance genes occurred; interpretation uses robust marker combinations and detection proportions, not undefined gene scores.
- The platelet cluster has only 13 profiles and might include platelet-containing droplets; the label describes the dominant transcript signature rather than confirmed intact cells.
