PBMC 3K: de novo single-cell RNA-seq analysis
===========================================
Input: user-specified 10x Genomics filtered hg19 matrix (genes.tsv, barcodes.tsv, matrix.mtx).
Genome context: human hg19; gene symbols from the downloaded feature table.
Analysis is computational; cell identities are hypotheses from marker expression, not independently validated truth.
No reference tutorial results, pretrained models, or hidden labels were used.

Input cells: 2700; QC passing: 2689;
Scrublet-predicted doublets removed: 36;
Retained: 2653 cells and 13624 genes present in >=3 retained cells.
QC: retain 200-2500 detected genes and <=10% mitochondrial UMIs per cell.
The input is already a filtered cell-barcode matrix. The upper complexity and mitochondrial
cutoffs target extreme outliers; they are heuristic, not external ground-truth QC labels.
Scrublet on QC-passing raw counts, expected doublet rate 0.06; automatic score threshold
0.3021. Predicted doublets removed; these are predictions, not confirmed multiplets.
Retain original integer counts in layers['counts']; library-size normalize X to 10,000 UMIs
and log1p-transform. Identify 2,000 HVGs via seurat_v3 on raw counts; scale only HVGs
(clip scaled values to 10), PCA 40 components; 15-nearest-neighbor graph, UMAP seed 42.
Leiden igraph resolution 0.7, undirected, two iterations, seed 42; resolution chosen
as a moderate-granularity exploratory setting, not to match any predetermined clusters.
One-versus-rest Wilcoxon tests with tie correction were run on log-normalized expression
for all retained genes, with FDR-adjusted p-values in cluster_markers.csv.
The marker table contains positive and negative DE results: check logfoldchange > 0
and p_value_adj < 0.05 when using a gene as positive cluster-level evidence.

Limitations and uncertainty:
Single sample, no donor/batch replication or protein validation. A small cluster can mix
rare related phenotypes; cell-level overrides in cluster 7 are tentative and not a
formal independent subcluster. CD4 is poorly detected in sparse single-cell data;
the CCR7+ and IL7R+ T groups may each include CD4 and CD8 cells, or state variation.
Scrublet is not a definitive doublet assay. No CellTypist reference model or
real-data CellTypist annotation was run. UMAP geometry is descriptive, not evidence
of developmental relationships. Differential-expression P-values are exploratory
because clusters were discovered using the same cells; no causal inference.
Markers with nonsignificant or negative cluster-level log2FC are contextual only.
All retained barcodes appear exactly once in cluster_assignments.csv.
