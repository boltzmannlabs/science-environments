
# Task: crispr_grna_design_001

Task Family: CRISPR Gene Knockout
Application: CRISPR-Cas9
Task Type: gRNA Generation and Candidate Ranking
Execution Mode: Boltzmann CRISPR Design
Status: Ready for execution

## Objective

Generate and retrieve ranked guide RNA (gRNA) candidates
for a user-specified target gene using the Boltzmann
CRISPR Design tool.

The task must work for any valid HGNC gene ID supplied
as input.

The objective is to obtain candidate gRNAs with sequence,
genomic location, efficiency, and specificity metrics.

## Input

The task requires two inputs:

1. Experiment name 
2. Gene ID

Example:

Experiment name: crispr_HPRT1_design
Gene ID: HPRT1

The gene ID must be a valid HGNC gene symbol.

The task must not hardcode HPRT1. It is an example only.

## Required Tool

Tool: Boltzmann CRISPR Design

The tool accepts:

- Experiment name
- Gene ID

The tool produces ranked gRNA candidates with:

- Spacer sequences
- PAM information
- Genomic coordinates
- GC content
- Off-target counts
- Predicted on-target scores
- Predicted off-target scores

The tool also provides a downloadable ZIP file containing
a CSV of designed gRNAs and their annotations.

## Execution Instructions

1. Read the experiment name and gene ID from the task input.
2. Validate that both input fields are provided.
3. Open the Boltzmann CRISPR Design tool.
4. Enter the experiment name.
5. Enter the target gene ID.
6. Execute the CRISPR Design operation.
7. Wait for the design operation to complete.
8. Retrieve the ranked gRNA candidates.
9. Download the result ZIP file.
10. Extract the CSV file containing all designed gRNAs.
11. Validate the output against the requirements below.
12. Generate the execution report.

Do not generate gRNAs using a separate tool.
Do not replace the Boltzmann output with manually
constructed candidates.

## Required Outputs

Create the following output bundle:

results/
  candidate_guides.csv
  execution_report.json
  validation_report.json

### candidate_guides.csv

Use the CSV generated by Boltzmann CRISPR Design.

Preserve all available annotations.

The output must contain the following information:

- Guide RNA sequence
- PAM
- Genomic coordinates
- GC content
- Off-target count
- Predicted on-target score
- Predicted off-target score
- Candidate ranking

Do not invent missing values.

### execution_report.json

Include:

- task_id
- experiment_name
- gene_id
- tool_name
- execution_status
- total_candidates_generated
- result_file
- execution_errors

### validation_report.json

Include:

- input_validation
- tool_execution_validation
- output_file_validation
- candidate_sequence_validation
- ranking_validation
- overall_status

## Validation Requirements

The task must verify:

1. The experiment name and gene ID were supplied.
2. The CRISPR Design tool completed successfully.
3. A result ZIP file was generated.
4. The ZIP contains the expected CSV output.
5. The CSV contains gRNA candidate records.
6. Required sequence and annotation columns are present.
7. Candidate rankings are present and interpretable.
8. Missing scores are reported as missing rather than
   replaced with fabricated values.
9. The execution report records the actual outcome.

If the tool fails, the task must report the failure
and must not fabricate gRNA candidates.

## Acceptance Criteria

The task is successful when:

- A valid gene ID is accepted.
- Boltzmann CRISPR Design executes successfully.
- Ranked gRNA candidates are generated.
- The result ZIP is retrieved.
- The CSV is extracted and validated.
- The execution and validation reports are produced.

The task must be reusable by changing only the experiment
name and gene ID.

## Final Deliverable

A validated CRISPR gRNA candidate dataset for the
user-provided target gene.

The task is computational only and does not perform
laboratory genome editing.
