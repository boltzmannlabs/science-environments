# FEP01 PTP1B benchmark

This is the paper-driven benchmark wrapper for the canonical PTP1B task. The
full molecular inputs and execution artifacts remain in
`tasks/fep_paper_002/`; this directory defines the common three-agent
comparison requested for the FEP module.

Current evidence and limitations are reported in
`tasks/fep_paper_002/reports/FINAL_REPORT.md` and
`results/reports/FEP_AGENT_COMPARISON.md`.
