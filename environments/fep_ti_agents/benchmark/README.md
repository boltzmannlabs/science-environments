# FEP/TI benchmark

Tracks include mapping and transformation validity, lambda schedule and
overlap, convergence/hysteresis, estimator uncertainty, charge corrections,
restraints/standard state, cycle closure, false-success auditing, and
independent qualification.

The toy TI track validates arithmetic and evaluator plumbing. SAMPL6 and
protein–ligand tracks require retrieved, hash-verified inputs and actual
window trajectories before scientific scoring.
