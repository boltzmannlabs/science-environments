# FEP-ENV-11 — Protonation and Tautomer Sensitivity

**Purpose:** Quantify how scientifically justified protonation/tautomer choices affect predictions.

**Inputs:** alternative states, pH assumptions, structures, mappings, and identical simulation protocols.

**Procedure:** validate each state, calculate comparable estimates, and report state dependence rather than selecting the most favorable result.

**Acceptance:** PASS requires complete provenance and uncertainty for each state; strong state dependence is a REVIEW finding.
