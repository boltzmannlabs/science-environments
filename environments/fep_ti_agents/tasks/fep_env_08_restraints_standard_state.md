# FEP-ENV-08 — Restraints and Standard-State Corrections

**Purpose:** Audit restraints, release terms, and standard-state conventions in binding calculations.

**Inputs:** restraint definitions, force constants, reference volume, release protocol, and leg results.

**Procedure:** independently calculate correction terms and check consistent application to every leg and replica.

**Acceptance:** PASS requires reproducible correction terms with declared units and conventions. Missing or inconsistent terms are REVIEW/FAIL.
