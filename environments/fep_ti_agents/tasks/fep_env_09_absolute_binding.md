# FEP-ENV-09 — Absolute Binding Free Energy

**Purpose:** Qualify ligand decoupling in complex and solvent for an ABFE protocol.

**Inputs:** decoupling schedule, restraints, soft-core settings, complex/solvent legs, and standard-state protocol.

**Procedure:** validate endpoint states, execute/inspect each leg, apply corrections, and independently audit convergence and uncertainty.

**Acceptance:** PASS requires complete legs, valid overlap/convergence, and an independently reproduced correction. This is a protocol task until a production backend and reference set are supplied.
