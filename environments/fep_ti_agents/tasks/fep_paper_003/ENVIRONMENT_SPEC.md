# FEP-PAPER-003 environment specification

This task follows the same packet structure as PTP1B and CDK2: frozen inputs,
independent reference metadata, four controlled configurations, machine
validation, execution evidence and a final qualification record.

The task is `REFERENCE_READY` after source-input validation. It becomes
`SETUP_VALIDATED` only after host/guest parameterization and complex/solvent
endpoint systems are independently checked. A scientific `PASS` additionally
requires lambda trajectories, overlap, convergence, uncertainty and an
independent estimator review.
