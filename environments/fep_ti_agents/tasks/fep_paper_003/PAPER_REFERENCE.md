# FEP-PAPER-003 — SAMPL6 OA-G3 → OA-G6

**Source:** SAMPL6 host–guest challenge repository.  
**Pinned source:** `https://github.com/samplchallenges/SAMPL6` (paths and
checksums recorded in `reference/parameters.json`).

The benchmark targets the octa-acid host with 5-hexenoic acid (OA-G3) and
4-methylpentanoic acid (OA-G6). The independently held experimental relative
target is `ΔΔG = 0.21 ± 0.028 kcal/mol`, defined as `DG(OA-G6) - DG(OA-G3)`.

The source structures are adequate for input identity and paper-to-setup
reconstruction. They are not a complete force-field/topology/trajectory
bundle, so this task is not yet a production FEP reproduction.
