# Task: fep_ag15_independent_qualification

## Description

Re-evaluate the complete FEP evidence package against frozen criteria without trusting the producing agent’s self-reported status.

## Dataset and inputs

- Inputs, methods, topology hashes, raw outputs, overlap/convergence/cycle reports, references, and limitations

## Tools to use

Independent schema/evidence validator, numerical recomputation, provenance audit, and qualification rules.

## Expected outputs

`qualification_report.json` with PASS, REVIEW, or FAIL; evidence links; unmet criteria; and reproducibility status.

## Acceptance and limitations

PASS requires complete traceable evidence and all frozen thresholds. This agent qualifies evidence, not the general validity of an experimental model.
