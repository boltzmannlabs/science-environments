# Results

Results contain execution evidence and qualification reports, not claims that
every contracted role is an autonomous AI agent or that every FEP calculation
is publication-qualified.

- `operational_role_audit.json`: contract-to-tool/evidence audit for all 25 roles.
- `paper_orchestration.json`: selected roles and missing gates for FEP-PAPER-001.
- `agent_architecture_benchmark.json`: A/B/C architecture comparison harness.
- `FEP_PAPER_BENCHMARK_REPORT.md`: human-readable milestone report.

`PASS` means the stated check passed. `REVIEW` means required scientific
evidence remains incomplete. Fixture results must not be promoted to production
free-energy evidence.
