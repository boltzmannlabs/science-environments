# Results

Results contain execution evidence and qualification reports, not claims that
every contracted role is an autonomous AI agent or that every FEP calculation
is publication-qualified.

## Result status

- `PASS`: the named check and acceptance criterion passed.
- `REVIEW`: required scientific evidence is incomplete.
- `FAIL`: a required check failed or a fault case was correctly rejected.

- `operational_role_audit.json`: contract-to-tool/evidence audit for all 25 roles.
- `paper_orchestration.json`: selected roles and missing gates for FEP-PAPER-001.
- `agent_architecture_benchmark.json`: A/B/C architecture comparison harness.
- `FEP_PAPER_BENCHMARK_REPORT.md`: human-readable milestone report.

Fixture results must not be promoted to production free-energy evidence.
Paper-task results are indexed under `fep_paper_002/` and retain source
hashes, commands, generated artifacts and limitations.

`case_study_preflight.json` records the sequential readiness check for every
case in the scientific catalogue.
