Data and provenance

FDA-hosted openFDA Recall Enterprise System (RES) drug enforcement reports were accessed through the documented drug/enforcement API. Two distinct ranolazine ER dissolution-related records were found: D-0092-2024 (Glenmark, 500 mg) and D-0010-2027 (Ajanta, 1000 mg; report date 2026-10-07). The suffix 2027 is an FDA recall identifier, not a report date. The records were queried again by exact recall number, and linked FDA-hosted SPL labels cross-checked by SPL set ID and package NDC. The direct FDA website search served an abuse-detection apology page, so this verification relies on FDA's public API rather than the weekly report HTML. FDA warns API results may be unvalidated or amended. The user specification (lines 7–19) remains a task description, not a source of recall facts. The raw JSON and SHA-256 identifiers are in data/raw and the processed episodes. There are no laboratory measurements in this repository. Numeric values in software tests are synthetic; numbers in imported recall/label records are FDA-reported values, not tests of dissolution.

For every real numeric observation capture evidence label, value, unit, source ID, method, timestamp, batch/material ID, model/tool version and uncertainty where applicable. Source identity and verification attestation must be traceable to an original approved source. The system does not cryptographically authenticate an attested citation. Keep raw source immutable under approved access policy; label processed derivations and transforms, freeze split manifests. Predictions are not measured labels. Disclosure of controlled product or lot data may be regulated; verify legal rights before ingestion or external processing. Missing: exact QC dissolution methods/specification ranges, lot-level measured dissolution profiles, batch-specific composition/material attributes, process and storage history. Manufacturer, strength and public lot code ARE documented per separate FDA case; source identity of the unspecified user-reported event remains ambiguous between the two.
