Evaluation protocol

A = fixed zero-tool evidence-gap baseline (implemented). B = authorized direct-tool SCI, C = same SCI plus six specialists, D = C plus trained/validated model/policy. B/C/D cannot run in this environment without approved scientific connectors and suitable data; do not report relative benefit prematurely. Freeze task, access permissions, budget, evaluation rubric, source sets and split seed before comparing; report failures, negative findings and costs. Require product/lot and replicate-family grouped split, with human leakage audit. Evaluate hard constraints, held-out error with units, target attainment only under verified specs, source accuracy, unsupported claims, API reliability and cost. models.uncertainty reports point error only on adequate holdout; it does not imply calibrated prediction intervals. When no measured holdout exists benchmark returns not_evaluated; next step is ethically permitted data acquisition/curation. Synthetic software fixtures are not a scientific benchmark.
