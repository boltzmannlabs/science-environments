# ADMETlab endpoint reference

Primary public source: [official endpoint catalogue](https://admetlab3.scbdd.com/diversity/), accessed2026-11-09. BCRP is listed as an inhibitor endpoint. The retained run responses additionally provide the endpoint display name and explanation; see the result audit’s `endpoint_definitions_as_returned.json`.

The audit uses those returned definitions for BCRP inhibition, BBB+ probability and the Caco-2 direction. It does not interpret an inhibitor probability as substrate transport. Original public-page retrieval hashes are retained in `downloads.json`; full website HTML is not distributed in the proposal.
