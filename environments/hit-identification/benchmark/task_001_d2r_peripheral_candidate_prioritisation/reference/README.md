# Reference material and attribution

The publisher article and supplementary data are by Kim, Jo, Cha and Kim (2026), [PLOS One DOI 10.1371/journal.pone.0355997](https://doi.org/10.1371/journal.pone.0355997), distributed under the article’s Creative Commons Attribution license. Original publisher files are retained without numerical edits. `main_tables.json` is a table-text export from the article XML.

- `paper.pdf`, `article.xml`: article snapshot.
- `s003.xlsx`: S1 Table,400 source compounds and historical ADME outputs.
- `s004.xlsx`: S2 Table,226 listed docking candidates plus reference.
- `s005.xlsx`: S1 Data, processed RMSD series; historical reference only, outside task execution scope.
- `response_text.txt`: extracted published author responses; see the [peer-review page](https://journals.plos.org/plosone/article/peerReview?id=10.1371/journal.pone.0355997).
- `downloads.json`, `publisher_refresh_check.json`: retrieval provenance and current-source checks.
- `admetlab_reference.md`: source links and a factual endpoint note. The returned execution responses themselves provide the inhibitor/BBB/Caco-2 definitions used in the audit.
- `diffdock_reference.md`: primary source links and a short sorting excerpt explaining confidence. Full third-party application code is not part of this proposal.
- `agent_scientist_reference.md`: [Agent Scientist](https://github.com/boltzmannlabs/Agent-Scientist) framework context. Its current README does not establish the version/model used by the delivered execution.
- `platform_score_interpretation.md`: retained local owner-supplied product-guide excerpt, identifying NESSO score semantics and the missing physical-unit specification.

Independent primary research on domperidone’s P-gp-mediated BBB transport: Breuil et al.2022, [DOI 10.3390/pharmaceutics14081658](https://doi.org/10.3390/pharmaceutics14081658). This does not turn a BCRP-inhibitor prediction into substrate transport evidence.
