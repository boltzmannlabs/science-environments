# Derived results (model-only)

`route_summary.json` contains 16 route records with exact model SMILES, route ranking and explicitly reconstructed steps; `illustrative_sequential_product_pct` is arithmetic on model step-yield fields, **not** a credible forecast of isolated target yield. `top0_validation.json` is a sanitized summary of completed platform calls and expert interpretation; it is not raw tool output. `retro_benchmark_report.docx` is rendered locally from these curated files.

The original service-export JSON, private backend handles, signed URLs, credential data and full external pages are not committed. See research notes and source links for experimental evidence limitations.
