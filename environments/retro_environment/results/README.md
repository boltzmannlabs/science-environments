# Results: what was obtained and what remains unproven

## Start here

[Achievements and literature comparison](achievements_and_comparison.md) provides the numerical results and reaction-level comparison tables. We obtained 16 computational pathways and identified unsupported conditions in the selected route; no experimentally improved synthesis was demonstrated.

| Output | What it contains |
|---|---|
| [route_summary.json](route_summary.json) | Every generated route, reactants/intermediates/products, explicit steps, model rankings and predicted step yields |
| [top0_validation.json](top0_validation.json) | Selected-route forward scores/product ranks, atom-map confidence, predicted conditions and scientific failure flags |
| [route_yield_comparison.csv](route_yield_comparison.csv) | Per-route numerical comparison; products of predicted yields are illustrative, not observed overall yield |
| [achievements_and_comparison.md](achievements_and_comparison.md) | Readable model-versus-literature tables, achieved counts and limitations |
| [achieved_metrics.json](../benchmark/achieved_metrics.json) | Recomputable metrics and null values for missing experimental measurements |
| [retro_benchmark_report.docx](retro_benchmark_report.docx) | Existing structure-based report with all 16 routes and 56 depicted transformations |

The original account-scoped exports, signed URLs, credentials and full third-party pages are withheld. JSON files are sanitized derivatives, not complete raw platform responses. Exact target experimental yield, selectivity, commercial precursor availability and a full matching literature route were not established.
