## Method and comparison criteria

The [sanitized route dataset](../../results/task-01-fluorinated-quinoline-retrosynthesis/route_summary.json) contains 16 predicted trees and [top0 review](../../results/task-01-fluorinated-quinoline-retrosynthesis/top0_validation.json) contains three stepwise model checks. Compare structures, precursor boundaries, explicit transformation counts and conditions against source-matched evidence. Model ranking, mapping, forward scores and predicted yields are model outputs, not measured reaction performance. [Metric definitions](../../benchmark/task-01-fluorinated-quinoline-retrosynthesis/achieved_metrics.json) mark unmatched experimental values as unavailable.

The [structured comparison](../../results/task-01-fluorinated-quinoline-retrosynthesis/comparison_report.md) separates model agreement, under-supported chemistry and missing head-to-head performance. No experimentally validated target route or superiority claim is established by these data.
