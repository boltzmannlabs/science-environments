# HOMO–LUMO Calculation Environment

**Status: Implemented (prototype); validation in progress.**

This environment calculates the orbital-energy HOMO–LUMO gap with PySCF and
validates input, SCF convergence, orbital occupations, units, and provenance.
It reports an eigenvalue gap only; it does not claim an optical excitation or
fundamental electronic gap.

## Quick start

```bash
python scripts/run_homo_lumo.py --tasks tasks/water.json tasks/methane.json tasks/benzene.json \
  --output results/prototype_results.json
```

The runner uses a frozen RHF/STO-3G protocol for the initial benchmark. All
values in `results/` are generated by the runner and include engine/version
metadata. Run from this directory with PySCF installed.

The 18 specialist contracts are listed in `agents/contracts.json`; the
prototype wires the validation, SCF, orbital-identification, gap, and reporting
checks into one deterministic path before specialist routing is expanded.

## Limitations

Open-shell alpha/beta treatment, orbital visualization, production reference
qualification, and three-arm agent comparisons are specified but not yet
qualified. Results must not be compared across incompatible methods or bases.

Problem-solving contracts are in [problem_solving/](problem_solving/), with
shared recovery logic under `../md_agents/recovery_agents/cross_domain/`.
