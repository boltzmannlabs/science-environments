# Acceptance and validation plan

Package checks validate the task/protocol schemas, 18 specialist contracts and
the deterministic runner. Scientific acceptance requires converged SCF, finite
orbital values, correct occupied/virtual indexing, independently recomputed gap
arithmetic, complete provenance and reproducible repeats.

The prototype is qualified only for the declared closed-shell RHF/STO-3G cases.
Open-shell alpha/beta treatment, orbital plots, cross-method references and
three-arm agent comparison remain pending.
