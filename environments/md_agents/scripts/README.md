# Execution and validation scripts

| Script | Purpose |
| --- | --- |
| `build_agent_input_manifest.py` | Build one packet per registered agent. |
| `run_paper_benchmark.py` | Compare general, specialist, and orchestrated setups. |

| `validate_paper_benchmark.py` | Check paper packet structure and hashes. |
| `qualify_paper_runs.py` | Apply conservative evidence gates. |

Preserve raw outputs and invocation records under `results/`.
