# Source code

The installable `formulation_environment` package contains one package per task:

- [Task-01](formulation_environment/task_01_clarithromycin_ir_formulation_dissolution/README.md): clarithromycin analysis and composition gates.
- [Task-02](formulation_environment/task_02_ranolazine_er_dissolution/README.md): ranolazine archive verification.

Python package names use the task folder slug with hyphens replaced by underscores. The root `__init__.py` is package metadata; scientific implementation belongs to the owning task.
