# Results and evidence

- `validation.json`: fresh integration commands, actual exit codes/output, Python/platform, distribution versions/licence metadata, direct imports, wheel/artifact hashes. Software checks only, not product validation.
- `validation.txt`: corresponding command output transcript; no credentials or private measurements.
- `historical_run_summary.json`: selected metrics/statuses extracted from the existing source-run outputs with source hashes. Historical literature reconstruction/synthetic/scenario results, not new lab data.
- `../SOURCE_PROVENANCE.json`: original source-relative paths/hashes, identical versus adapted copies, and local-only external artifacts. Originals remain unchanged. The full prior gym is not claimed to be a portable measured dataset.
- `../data/processed/six_model_pipeline/`: bounded synthetic regression/results fixture, plots, split IDs and mechanical audit. Prior patent-summary and scenario artifacts remain explicitly labeled. Individual source/lab results are absent.

Repeat with `python scripts/check_release.py` after installing the documented optional dependencies plus build/Ruff. Use new `.runs/` directories for manual examples; the release checker uses timestamped `.checks/`. Those directories, virtualenvs, caches, approvals, live lab jobs and local configs are ignored. Full patent HTML and coding-agent reviews are indexed local-only rather than redistributed.

Synthetic test RMSE is not ranolazine predictive accuracy. Scenario scores/percentiles are conditional on unverified ranges and arbitrary goals/weights. Interval calibration, commercial QC attainment, mechanistic applicability, improved formulation, experimental validation and base-agent superiority remain unestablished.
