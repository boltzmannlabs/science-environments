Architecture and trust boundaries

Each episode records task, attested sources, material inventory, constraints, candidate/prediction registries, experiment ledger, evidence, hypotheses, ranking, audit and budget. Actions are the only supported state-transition interface. Persist via atomic JSON replacement. Independently verify via evaluation.verifier.verify and agents.evidence_auditor.audit. The orchestrator does not call specialists without prerequisite input; absent records trigger abstention. Six agent modules are pure, typed, bounded functions rather than autonomous subprocesses; do not add more without controlled comparative evidence.

Registry contracts must come from documented authorized APIs. Capabilities with no contract return tool_unavailable. Prediction results carry provenance; all physical work needs separate authorization. Composition validation is arithmetic only, never proof of biopharmaceutical equivalence. import_fda.py validates saved public FDA enforcement/label responses and creates separate episodes; it is not an authenticated connection to a firm's controlled QC or manufacturing records. The active SCI delegation tool is disabled; the six specialist contracts execute as local bounded functions, not separately spawned agents.

Proposed transitions: verified source -> registered material -> validated candidate -> optional prediction/compatibility -> approved proposal -> authorized measured record -> ranking -> verifier -> finalization. Baseline needs no access to specialist tools; no scientifically substantive conclusion is asserted on absent records.
