# Six-model dissolution pipeline: executed result and boundaries

Run from the repository root with Python in an isolated environment containing OpenPKFlow 2.9.0, NumPy, SciPy and Matplotlib:

    python -m evaluation.six_model_pipeline --literature data/processed/literature_profiles.json --out data/processed/six_model_pipeline
    python -m evaluation.six_model_verifier --result data/processed/six_model_pipeline/six_model_results.json --fixture data/processed/six_model_pipeline/synthetic_batch_fixture.json --out data/processed/six_model_pipeline/verification.json

The implementation fits Weibull, first-order, zero-order, Higuchi, Korsmeyer–Peppas and Hixson–Crowell forms via the installed `openpkflow.dissolution.models.fit_dissolution_models` v2.9.0 public API. Time is minutes and cumulative release is percentage of nominal dose. Power-law fits are restricted to early points at or below 60%: late predictions are extrapolations. Model failures and missing point support remain in the ledger; observed values >100% are not silently clipped. Full-curve AICc is not compared with early-only power-law AICc.

Published literature fitting: 59 converged model/profile fits across seven pH 6.8 summary curves and three low-pH sustained-release curves, with one power-law exclusion for too few early points. IR and the single F8 endpoint were excluded. Fitting/scoring the SAME published curve is in-sample reconstruction, NOT unseen formulation or batch prediction. pH 6.8 numbers came from the user-supplied patent transcription whose QuickCompany source returned 403; the separate US6525057B2 low-pH table sequence was checked against primary patent HTML. No individual-unit data, variance or matched Ajanta QC method exists. The macro in-sample RMSE for pH 6.8 summaries is 2.1124 pp for Weibull, 8.0500 pp first-order, 14.3269 pp zero-order, 4.0609 pp Higuchi, 4.9293 pp early-fit Korsmeyer–Peppas (then extrapolated), and 9.9145 pp Hixson–Crowell. The low-pH summaries are tabulated separately in `six_model_results.json`; do not pool media or regard the lowest in-sample error as demonstrated product predictive superiority.

Synthetic-only batch fixture: 24 explicitly simulated batches over four arbitrary labels, generated with a Weibull law and declared invented rate scales, batch effect and point noise. The split is by complete batch: 12 train, 4 validation and 8 test. Each model is fitted only on training mean profiles; model selection uses validation RMSE, and independent test-batch metrics are reported as a software test. Test profile macro RMSE (pp), excluding the common zero-time anchor: Weibull 1.8417, first-order 3.6708, zero-order 18.9839, Higuchi 5.2031, Korsmeyer–Peppas 22.7430 and Hixson–Crowell 5.8523. Weibull was selected on validation and also has lowest synthetic test error because the fixture was generated using Weibull; this is NOT evidence of ranolazine accuracy. The JSON contains per-batch MAE/RMSE/signed bias, residuals by time, nominal 90% interval half-widths and empirical test coverage; interval calibration is NOT established with four validation batches. Mathematical f2 is provided only for in-range synthetic batches and is NOT a regulatory extended-release f2 similarity decision. Per-test plots and CSVs are under `data/processed/six_model_pipeline/`. Independent verifier found no mechanical leakage/metric/label findings.

Mechanistic modeling was not run: product-specific PSD, solubility/solid state, tablet matrix transport inputs, approved method and measured unit profiles are absent. PTCalc has no installed/documented approved tool contract in this session. No mixture-aware predictor was trained: no eligible source-verified measured ranolazine composition-to-profile training set exists. Ajanta lot DJ25134 cannot be scored against approved QC limits from these files.

Exploratory 500 mg F1–F8 research-prototype optimization and sensitivity are separately executed in `data/processed/ranolazine_500_exploratory_new_run.json` and `ranolazine_500_selected_benchmark.json`. All optimization goals/rate priors/ingredient-effect signs are ASSUMED; the zero-effect negative control shows a ranking can remain solely from a polymer-mass preference. This is not a commercial formulation recommendation or experimentally validated improvement.

Independent read-only agent findings: `data/processed/model_subagent_review.txt`, `validation_subagent_review.txt`, `provenance_subagent_review.txt`. Their recommendations do not change evidence labels. Source data remain read-only.
