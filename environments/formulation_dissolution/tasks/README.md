# Tasks

Definitions in [formulation_dissolution_tasks.yaml](formulation_dissolution_tasks.yaml) are JSON-syntax YAML. They reference the existing executables/configs; they are not a second scheduler. Synthetic scenarios do not represent an experimentally verified marketed-product failure. No task grants permission for physical experiments or product changes.

Run commands from the environment root after installing the optional simulation/test dependencies. See [README](../README.md) and [specification](../ENVIRONMENT_SPEC.md).

Task success means the stated software/evidence contract is met, not a successful commercial formulation. Compatibility/stability success can legitimately be explicit insufficient_data. A numerical optimization winner is not an experimentally validated product.
