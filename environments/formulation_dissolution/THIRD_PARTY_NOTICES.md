# Third-party materials and restrictions

The repository root LICENSE says licence selection is pending; this contribution does not introduce an open-source licence grant for repository code. Public hosting and package installation do not remove source-specific restrictions or patents.

No third-party scientific library source, model weights, original article PDFs or restricted laboratory dataset is vendored. OpenPKFlow 2.9.0 is installed from its distribution (MIT metadata); NumPy/SciPy/pandas use BSD-family licensing, Matplotlib its own licence; transitive dependencies keep their upstream notices. Exact distribution versions and licence metadata are recorded in results/validation.json. Check installed licence files for deployment/redistribution.

The public FDA/openFDA JSON and DailyMed label XML snapshots are historical identity regression fixtures, with original API source/terms/disclaimers preserved. openFDA source metadata points to https://open.fda.gov/license/ and https://open.fda.gov/terms/ . Manufacturer-submitted labeling is not a blanket rights grant or medical recommendation. Neither FDA publication nor this repository authenticates manufacturer GMP records.
