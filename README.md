# Science Environments

This repository contains reproducible scientific environments. The maintained
environments currently are:

- [`environments/spe_agents`](environments/spe_agents): specialist
  single-point-energy workflows.
- [`environments/geo_opt_agents`](environments/geo_opt_agents): specialist
  molecular geometry-optimisation workflows.

Each environment contains its own specification, references, tasks, tests,
and versioned result evidence. See [`CONTRIBUTING.md`](CONTRIBUTING.md) before
making changes.
